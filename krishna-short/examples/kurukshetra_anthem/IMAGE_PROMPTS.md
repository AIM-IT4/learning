# Cinematic artwork for the Kurukshetra Anthem reel

Make these with any free AI image generator that does **portrait / 9:16** images, for example
Microsoft Designer (Bing Image Creator), Google Gemini, Meta AI, Ideogram or Leonardo.
Check the tool's terms for social-media use.

**How to use**
1. Paste the STYLE line + one shot prompt. Pick **9:16 / portrait** if the tool asks.
2. Generate 2–4 options, keep the most epic one.
3. Save it with the file name shown (i01.jpg, i02.jpg … drop.jpg, outro.jpg).
4. Put all 18 images in one Google Drive folder named `anthem images` and tell Claude.
   The reel is re-rendered on the same song, beats and captions.

Keep Krishna looking the same in every image: always add the CHARACTER line when Krishna is in the shot.

## STYLE (add to every prompt)

```
epic Indian mythology digital painting, cinematic lighting, dramatic glow, ultra detailed,
deep blue and fire orange colours, floating embers, volumetric light, vertical 9:16, no text
```

## CHARACTER (add when Krishna appears)

```
Lord Krishna with deep blue skin, golden crown with peacock feather, calm divine eyes,
yellow silk dhoti, pearl and gold jewellery, glowing golden halo
```
